# Habit Flow

Habit Flow — простой персональный трекер привычек и разовых задач. Интерфейс приложения на русском языке, а данные сохраняются локально в браузере.

## Возможности

- Создание, редактирование и удаление привычек.
- Ежедневные отметки выполнения и подсчёт серии дней подряд.
- Перетаскивание привычек для настройки порядка; выбранный порядок запоминается в браузере.
- Просмотр активности за последние 30 дней — общей или для отдельной привычки.
- Создание и отслеживание разовых задач на сегодня.
- Перетаскивание задач для настройки порядка; выбранный порядок запоминается в браузере.
- Индикаторы выполнения привычек и задач за текущий день.
- Экспорт данных в JSON и импорт резервной копии.
- Адаптивный интерфейс для компьютеров и телефонов.

## Запуск

Приложение не требует установки зависимостей или сервера:

1. Скачайте или распакуйте проект.
2. Откройте файл [`index.html`](./index.html) в современном браузере.

## Хранение данных

Данные хранятся в `localStorage` текущего браузера на текущем устройстве. При очистке данных браузера они могут быть удалены. Чтобы перенести их на другое устройство, используйте кнопки экспорта и импорта JSON в разделе «Данные».
