# Habit Flow

Habit Flow — простой персональный трекер привычек и разовых задач. Интерфейс приложения на русском языке, а данные сохраняются локально в браузере.

## Возможности

- Создание, редактирование и удаление привычек с описанием.
- Сворачиваемые карточки: в свёрнутом виде видны только название, отметка и статус,
  описание и кнопки действий открываются кнопкой-шевроном. Состояние сбрасывается при перезагрузке страницы.
- Ежедневные отметки выполнения и подсчёт серии дней подряд.
- Перетаскивание привычек мышью или стрелками клавиатуры; выбранный порядок запоминается в браузере.
- Просмотр активности за последние 30 дней — общей или для отдельной привычки.
- Нажатие на день в календаре открывает список привычек с возможностью изменить отметки за выбранную дату.
- Страница «План на месяц»: кнопка в верхней панели рядом с настройками открывает отдельный экран
  (`#/plan`), где можно выбрать или перетащить локальный файл `.md` и посмотреть его содержимое
  в оформленном Markdown-виде или в исходном коде.
- Разовые задачи на сегодня и задачи, запланированные на будущие даты.
- Приоритетные задачи: можно пометить задачу как приоритетную — она получит красный флажок и переместится в начало списка.
  Переключить приоритет можно на карточке задачи или в форме редактирования.
- Подзадачи: у задачи и привычки можно добавлять несколько подзадач, отмечать их выполнение и удалять.
  На карточке отображается чип прогресса (например, «2/4 · 50%»), а в развёрнутом виде —
  полный список подзадач, индикатор выполнения и поле для добавления новой подзадачи.
  Подзадачи не влияют на общие полосы прогресса за день.
- Проекты: остаются в списке, пока не выполнены, с указанием возраста в днях.
  Раздел проектов изначально свёрнут; в заголовке видны шеврон и количество проектов.
  Их можно создать из `.md`-файла кнопкой «Импорт .md» в разделе проектов:
  имя файла станет названием проекта, чекбоксы — подзадачами, отметки выполнения сохранятся,
  а названия вложенных пунктов будут начинаться с `--`.
- Перетаскивание задач мышью или стрелками клавиатуры; выбранный порядок запоминается.
- Индикаторы выполнения привычек и задач за текущий день.
- Экспорт данных в JSON и импорт резервной копии.
- Адаптивный интерфейс для компьютеров и телефонов, поддержка клавиатуры и экранных читалок.

## Запуск

Приложение не требует установки зависимостей или сервера:

1. Скачайте или распакуйте проект.
2. Откройте файл [`index.html`](./index.html) в современном браузере.

## Хранение данных

Данные хранятся в `localStorage` текущего браузера на текущем устройстве. При очистке данных браузера они могут быть удалены. Чтобы перенести их на другое устройство, используйте кнопки экспорта и импорта JSON в разделе «Данные».

Если хранилище недоступно (например, приватный режим браузера), приложение продолжает работать, но сообщает, что изменения не сохраняются.

При открытии файла в двух вкладках данные синхронизируются автоматически.

## План на месяц

Файл плана читается только на устройстве: он никуда не отправляется и его содержимое не хранится
в браузере. Поддерживаются заголовки, списки, вложенные списки, чек-листы, таблицы, цитаты,
блоки кода, ссылки и изображения.

Выбор файла запоминается: в `localStorage` под ключом `habitFlow.planFile.v1` сохраняется
идентификатор (имя, размер, дата изменения и дата выбора). После перезагрузки страница
показывает, какой файл был открыт последним, и предлагает выбрать его снова — содержимое
файла восстанавливается только так, потому что браузер не даёт странице читать файл без
повторного выбора пользователем. Кнопка «Очистить» удаляет и содержимое, и сохранённый выбор.

## Структура

Всё приложение находится в одном файле [`index.html`](./index.html): разметка, стили и скрипт.

- `defaultState`, `normalizeState`, `normalizeHabits`, `normalizeTasks`, `normalizeOrder` — единая нормализация данных при загрузке и импорте.
- `createView` — единая выборка задач на сегодня и в будущем.
- `render` и `renderStats` / `renderTasks` / `renderHabits` / `renderCalendar` — отрисовка.
- `enableDragSort` — сортировка мышью и стрелками для обоих списков.
- `applyRoute` / `navigate` — переключение между экранами трекера и плана через адресную строку.
- `loadPlanFile` / `renderPlanDocument` / `setPlanView` — загрузка `.md` файла и переключение
  между оформленным и исходным видом.
- `normalizePlanSelection`, `savePlanSelection`, `loadPlanSelection`, `forgetPlanSelection`,
  `isSamePlanFile`, `renderPlanSelection` — сохранение выбранного файла в `localStorage`
  (только идентификатор) и восстановление выбора при запуске.
- `renderMarkdown` и вспомогательные `parseMarkdownBlocks`, `renderListItems`, `collectTable`,
  `renderInline` — собственный рендерер Markdown: заголовки, списки, вложенные списки, чек-листы
  (`- [ ]` / `- [x]`), таблицы, цитаты, блоки кода, ссылки и изображения, emphasis, переносы строк.
  HTML экранируется, ссылки ограничены безопасными схемами (`http`, `https`, `mailto` и относительные пути).
- `normalizeSubtasks`, `subtaskStats`, `toggleSubtask`, `addSubtask`, `deleteSubtask`,
  `taskMeta`, `subtasksSection` — подзадачи для задач: нормализация при загрузке, расчёт прогресса,
  отрисовка чипа и развёрнутого списка, добавление и удаление, делегирование событий.
